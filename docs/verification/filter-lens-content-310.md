# 聊天筛选按压玻璃修复（2026-11-20）

用户实机截图显示：顶部筛选按住后只有深色块，底部Dock却有放大文字／图标及玻璃边缘。之前的测试只证明透镜越出底壳，在棋盘背景上有画面变化，未覆盖平坦深色聊天页，因此不能代表该问题已解决。本次仍属未发布1.0.310。

## 根因与修复

筛选原先只采样页面背景，文字绘在透镜上方；按下时撤掉静止底色，但没有Dock的边缘高光。在列表顶部的平坦深色区域，得到的就是没有可辨边缘的深色块。原生基线在MuMu上复现，新用例预期失败，亮边像素为0。

筛选现在组合独立的页面、胶囊底壳、标签文字三层，透镜绘在标签之上，文字参与折射与按压放大。只录制兄弟节点，不录制透镜自身，不新增一套标签交互或无障碍节点。共享Dock原有随重力变化的高光，保留固定采样边距、色散与阴影；取消文字层额外模糊。缩放通过drawBackdrop的layerBlock传入，背景采样能使用相反变换保持标签居中。没有玻璃源时仍使用原底色和原缩放。

本次生产改动共4份文件：SteamGlassSelectionRow、SteamGlassSelectionLens、SteamListFilterRow和SteamLiquidGlassDock。Dock仅将原高光辅助类型／函数共享，参数不变。拖动、滚动、取消、生命周期和选择状态机未改；未修改聊天缓存／网络／加密。

## 中间失败与范围

第一次组件修复已出现亮边／文字折射，但外部缩放没有进入采样逆变换，文字偏到右下角；原生图与fixed-device01的1/2结果保留。通过layerBlock校正。初版亮边断言只统计容器外且要求绝对RGB和240，漏掉实际轮廓，改为与基线比较的放大椭圆环，并增加文字居中、放大断言；离线基线环亮像素0，错误中间版中心文字46，均不能通过最终要求。

fixed02的27项中26通过，唯一松手画面对比失败：初始截图捕获了系统窗口淡入，整张棋盘偏暗。补400ms平台窗口等待，未降低原恢复断言。最终整批通过。baseline APK被后续Gradle输出清理，最后尝试配新测试重跑旧主包时路径不存在；保留原红测、截图和SHA，但未声称最终测试包重新执行过旧主包。最终APK已留本地任务raw目录，无交付。
