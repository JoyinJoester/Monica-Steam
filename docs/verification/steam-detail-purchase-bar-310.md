# Steam 游戏详情底部购买栏 — 310 验证

2026-11-21；未发布 1.0.310 / code18，验证标识 26112118-43。工作目录为 Monica Steam，保留所有前序未提交改动。

## 行为

- 从商店或游戏库进入游戏详情时，根 Dock 隐藏；退出详情恢复原根导航。宽屏也撤销已隐藏导航栏的空白左侧占位。商店按详情路由报告可见性，游戏库按选中游戏报告，避免新旧详情过渡销毁导致误报告。
- 商店、个人统计及创意工坊共用底部悬浮购买栏，含心愿单状态、价格及可验证的折扣剩余时间。内容和侧边工具栏避让实测浮条高度与系统导航栏；底栏不采样自身。
- 购买打开原生滚动 sheet，选择版本/包、加入购物车或送礼；免费领取也统一在 sheet。捆绑包继续显示内容，并使用现有官方 Steam 购买入口。已拥有时禁止为自己重复添加，但地区允许时可送礼；地区不可购买时保留官方页面入口。
- 截止时间来自官方 HTML data-props 内 rgStoreItems 的匹配 appid 和购买 packageid。只采纳有效折扣、数字时间戳，并与最终包价格/折扣匹配；冲突、其他游戏/包、免费通行证及 bundle 元数据不提供误导倒计时。过期后底栏使用购买选项文案，不再显示旧折扣价格为当前购买价。
- 新增中英日越俄共 20 条短标签，复用主题、M3E 磨砂与液态玻璃材质。可编辑 Canvas、完整分享 URL、设计预览与设备图片只在忽略的 docs/design/20261121-detail-purchase-bar 中保留，不进入 Git。
