# Steam chat voice activity motion

Date: 2026-11-20. Version: unreleased 1.0.310 / code 18. Scope: chat call banners and group voice member rows.

## Behavior and source reference

The local Telegram snapshot supplies the interaction references: `ui/Components/voip/VoIPStatusTextView.java:179` replaces labels with an 8 dp entrance, a 6 dp upward exit and a 250 ms transition; `ui/Cells/GroupCallUserCell.java:962` uses two avatar contours, amplitude smoothing and a LiteMode animation gate. Steam implements these ideas independently in Compose, retaining its theme and actual call state. No Telegram audio engine is imported.

Call labels now use a short upward fade, smooth size changes and immediate current accessibility text. Fast changes resolve to the newest status. Direct-call banners show the called participant's avatar, resolved from the active call identity even when another thread is open. Group voice rows show individual member waves. Two soft contours and a small avatar scale respond to measured amplitude; silence decays to stillness. Reduced motion substitutes a static speaking ring and immediate status changes. Status resources cover English, Chinese, Japanese, Russian and Vietnamese (40 values).

## Audio path

The existing hidden Android WebView retains its platform WebRTC engine and five-second media-health diagnostics. A separate 120 ms, non-overlapping RTC stats sampler runs only with a connected call and visible avatar subscribers. It reads scalar `media-source` and `inbound-rtp` levels, falling back to energy/duration deltas if audioLevel is unavailable. It neither records audio nor adds microphone capture or native dependencies. Unsupported stats leave the avatar still.

Local levels use the call account identity; remote SSRCs must match the server-provided participant map and current participant/direct-call membership. Unknown streams are discarded. Mute, output mute, participant departure and connection state gate the display. Remapping and media replacement clear previous levels; revision/peer tokens reject late stats. Remote description updates suspend sampling until the queued descriptions are applied. Main-thread bridge delivery rechecks engine lifetime and rejects delayed meter callbacks. Samples expire after 600 ms without updates. Audio levels remain a separate transient StateFlow, so they do not drive the call notification or whole chat-page state.

The local editable M3E Canvas project is `steam-voice-motion-20261120`; its JSON, full local sharing link, preview and native screenshots remain under ignored `docs/design/20261120-voice-motion/`. Images are not committed or embedded in this report.
