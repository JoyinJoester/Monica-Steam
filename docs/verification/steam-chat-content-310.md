# Steam 聊天内容 — 1.0.310 未发布验证

2026-11-21，版本 1.0.310 / code18，隔离 Debug 标识 26112118-40。

## 变更

- 私聊、群聊资料页的“共享内容”改为“聊天内容”。标题使用 Material titleLarge，标题与分类之间增加 14dp 空白；分类复用 M3E 高斯磨砂胶囊和液态玻璃选择器，支持按住放大、拖动、松手提交及取消恢复。玻璃只采样独立页面背景，标题和透镜不反馈进自己的背景。
- 图片、视频、贴纸按已加载消息的月份倒序展示，每行三格、格间 3dp。资料页仍使用一个 LazyColumn；其他资料区保留原 12dp 间隔，媒体网格独立采用紧凑间距。M3E 媒体格圆角 12dp，液态玻璃样式 4dp。
- 分类器保留附件种类、原 URL 和剧透状态。视频只使用消息实际提供的图片作为封面，不把视频 URL 交给图片解码器；无封面时显示视频标识。剧透格不加载缩略图。每条消息仍计入一个分类，未新增自动拉取更早消息、视频下载或时长探测。
- 文件、链接、邀请使用类型图标和分层文字，显示发送者及本地化发送日期时间；文件直接显示名称。点击媒体或列表内容仍回到原消息。
- 英文、中文、日文、越南文、俄文资源补齐，保留旧资源键以兼容调用。120 个实际编译值逐项匹配源资源，并检查同目录字符串键唯一及格式占位符。

## 验证

最终 build03 主包、测试包与 JVM 联合构建成功，驱动耗时 58.538 秒。61 项 JVM 全过，无失败或跳过：新增媒体元数据 3、分类 14、查询 9、源码集成检查 6、富媒体模型 29。源码检查不等同于设备交互测试。

复用已有 MuMu1，API35 / x86_64，安装独立 `.chatcontent` 包，仅使用合成消息和缓存内合成图片，无真实 Steam 账号或截图里的私人内容。

## 前序失败

- build01 主包和测试包生成成功，JVM 60/61。旧集成检查仍要求筛选调用 `SteamListFilterChip`，而此前共享胶囊已改用 `SteamGlassSelectionRow`。将该检查更新为验证共享选择器、标签/计数和 48dp 目标；其他原有检查保留。未为满足过时检查改回生产 UI。
- device01 为 5/6。原生截图已显示抬起透镜，但检查只接受单通道明显变亮，深色边缘未跨过阈值。改用 RGB 总色差，仍要求原分类格上方至少 30 个变化像素；保留相同区域与抬起要求。旧日志、APK、测试源码及原截图均保留本地。
- build02 JVM61、device02 7/7、regression01 3/3 通过后，截图发现文件标题带旧中文类型前缀。整理成文件名并加实际标题断言，再完成最终 build03 / device03 / regression02。没有将中间包的结果当作最终包验收。

## 清理与限制

仅卸载本任务 `.chatcontent` 主包和测试包，停止本任务启动的已有 MuMu1。原用户及原应用包、当前用户、屏幕尺寸、密度和字号核对保留；预先运行的 MuMu0 保留，配置与数据盘未删除。原始设备清单仅在私有任务目录，提交候选证据只保留清理布尔结果。

限于 API35 / x86_64 / Debug 的合成数据。没有真机、OEM、R8、真实账号网络加载或全部历史媒体验证。无封面视频显示类型占位，未保证每条 Steam 视频都有缩略图；“聊天内容”索引仅覆盖当前已加载消息。未提交、推送、发布或交付 APK。
