# 蒸蒸空间成就图标验证（2026-11-07）

蒸蒸空间的成就动态新增 56dp 圆角图标，右侧显示可换行名称和说明；加载中或缺图显示主题色奖杯。使用现有后台图片加载及磁盘缓存，URL 改变时清除旧图片状态，装饰图不重复朗读相邻名称。

核对 Steam 客户端 `BuildAchievementMapFromProto`：UserNews 成就的 `icon` 字段是相对文件名，客户端按游戏 ID 拼接社区图片目录。原解析只接受完整网址，会丢弃这种文件名。本次兼容文件名和既有完整 CDN 地址，文件名不能携带路径、查询或片段；保留原有图片域名校验和只读数据接口。
