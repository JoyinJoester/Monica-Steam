# Remove manual Steam-card sharing · 1.0.310 (unreleased)

The chat composer had a separate manual link-sharing sheet with profile/inventory/broadcast shortcuts and an extra pending-URL draft. Those URLs already work when pasted into the normal message field. The sheet, its composer button/state/preview and 55 unused strings across five locales have been removed. Private and group chats use the same simplified composer. The native input has no menu callback, hides the empty-state menu action and gives its space back to the input; the send animation retains its slot until the transition finishes.

Pasted URLs still use the original text send path. Incoming and sent Steam card parsing/rendering, card actions, trade access from chat details/history and existing game-detail share drafts remain. No chat database, message, account or server data was changed. Prior liquid-glass quick-tap, collection swipe, achievement icon and review-author sources match their previous hashes.
