# Steam 底部面板设计改版（2026-11-14）

本轮完成共享玻璃浮层外壳及七个常用面板的内容布局。此前成就分类、Dock 与页面联动改动保留，验证记录分别见同目录已有报告。

## 实现范围

- 外壳左右及底部留白 10dp，四角 32dp；玻璃绘制位于 Material 已平移的容器内，保持拖动、展开、收起、拒绝关闭和关闭时序。
- 内容统一标题／关闭按钮、分组标题、连续分组圆角、圆角搜索框、选中标记与底部操作区。内部组使用主题颜色，没有新增独立模糊、折射或背景消费方。
- 游戏库筛选：所有权连续选择行，其余选项扩大触控区域并允许换行；保留预览计数与未应用草稿，重置及应用位于底部。
- 商店高级筛选：分组选择和固定应用区，完全展开以避免半展开时操作落在屏幕外；保留价格、语言、标签、重试及草稿确认。
- 账号切换和好友账号选择：连续分组、明确选中状态、受限 LazyColumn；添加账号可达，临时账号退出仍经原确认弹窗。
- 游戏分享、赠礼收件人：统一标题／好友搜索／选择行；外部分享位于底部，赠礼仍保留验证提示和既有选择回调。
- 聊天卡片：圆角输入、就地错误及固定主操作；加入草稿后仍由用户手动发送，无效链接不能添加。

调用盘点含 31 个 Steam 文件。其他专业面板本轮仅继承共享外壳，没有全部重排内容。M3E 和不支持玻璃的回退仍保留可用的主题容器。没有新增应用文案，沿用现有字符串资源与主题字体。

## 设计与验证

先在既有本地 M3E Canvas 中制作并检查四页可编辑设计，再实施原生布局。草图、完整链接和截图仅保存在忽略的 `docs/design/glass-sheets-20261114/`，不纳入版本控制；浏览器预览保留。Canvas 的 stock bottomSheet 下角固定为直角，草图用同色几何层补齐浮动圆弧，已检查实际单页渲染和页面跳转。

最终安装使用隔离离线 Debug 包 `takagi.ru.monica.steamapp.sheetdesign`，MuMu index2、Android15/API35/x86_64、合成账号与好友。公共 API32 无法覆盖 AGSL，未新建 AVD。

- fixture06 联合构建 172.142s，相关 JVM 共 31 项，失败／错误／跳过均为 0。
- fixture07 主／测试包构建 65.311s；26 项设备整批中 25 项通过、真实 IME 观察 1 项失败，runner 43.473s。七个面板的深浅色玻璃／M3E、大字号、长列表、应用／重置／关闭／无效草稿和既有拖动语义已有通过结果。
- 原搜狗输入法诊断显示输入连接及显示请求已建立，但窗口请求高度为 0、触控区域为空；对应截图没有键盘。不能将此运行视为真实 IME 验收。
- 测试 APK 新增独立 InputMethodService，仅用 Java 平台控件绘制合成键盘，不访问用户 Monica 输入法或凭据。fixture11 构建 32.037s；native11 原生用例 1/1，通过 2.345s，验证真实非零 IME 窗口、无效链接禁用操作在键盘上方、第一次返回隐藏键盘／第二次关闭面板、零添加及背景消费者归零。已检查带键盘截图。
- small11 在 320dp、代表性 1.5 倍字号及三项系统动画比例 0 下补测库筛选、商店筛选、账号和分享，共 4/4，通过 7.371s。正常实测为 360dp，字号 1 与 1.5。横屏、平板及全部语言尚未本轮验证。

26 个不同设备方法分别取得通过结果，并非原整批全绿。相关生产源文件及 fixture07 主 APK 与最终测试包使用的主 APK 完全一致；后续变化仅为独立 IME 夹具和原生测试节点查找。无理由重复已通过的常规方法。

正式应用 ID、x86_64、正常 R8／资源压缩 Debug 构建结果和 APK SHA256 见配套 `glass-sheets-20261114-results.json`。正式包仅打包，未安装到用户正式包；运行时验证使用未压缩隔离夹具，不等同于 R8 运行验收。

## 失败与限制

早期 key 参数、测试依赖／赠礼签名、internal 类型暴露和半展开布局失败保留；构建期间曾修改测试导致旧输入，后续构建冻结源码再运行。合成查询“80”误匹配全部 SteamID 改为“friend 80”，没有修改生产搜索。

fixture08 独立测试 APK 不带目标应用的 Kotlin stdlib，导致测试输入法进程 ClassNotFoundException，改为 Java 平台实现，未增加生产依赖。fixture09／10 原生节点查找先误读启用的文字节点／角色节点；fixture11 通过包含相同标签的禁用语义容器验证。native11 方法通过后图片提取器因新增 txt 诊断文件退出，修复提取器并单独重取文件，没有将提取失败记为测试失败或重跑来覆盖日志。早期 adb shell PNG 换行损坏另行保留，最终采用 exec-out 提取。

实际截图采用合成棋盘背景和主题默认配色，仅代表上述组件。没有用户真机、OEM 输入法、真实账号联网、全部专业面板内容或正式 R8 运行验收；不能据此称所有浮层和全部玻璃卡顿已经解决。
