# 搜索与筛选统一验证（2026-11-14）

本轮修复用户截图中的筛选文字偏右、换行不居中，并完成搜索与筛选样式收敛。未发布版本仍为 1.0.310；没有提交、推送、发布或交付 APK。此前成就集合和聊天切页性能修复保留。

## 最终行为

- 商店主页保留现有搜索胶囊；聊天、好友、成员和历史页使用游戏库标题／展开搜索布局，内联搜索共用原生编辑器。查询、输入法 composing、光标、清空与提交保留；好友查询长度限制、请求中状态与提交门控保留。
- 聊天／联系人／历史分类条从任意选项起拖，松手提交；未形成拖动、取消、页面停止或被替换时恢复当前选择。保留边缘滚动、垂直滚动归属及固定样式的拖动支持。
- 商店价格和语言改为换行布局，标签搜索和默认热门标签直接可见。展开扩大有界标签数量，搜索匹配完整元数据，已选标签仍保留。应用提交整组 draft，关闭不提交，重置保留原语义。
- 共用筛选胶囊使用对称文字空间，单行和每行换行文字均居中；选中勾独立定位。容器提高不透明度，背景不干扰标签阅读。另 13 个筛选调用路径统一适配共用游戏库样式，图标、计数与状态点保留。
- 实际系统字号 1.5 揭示原生 TextView 残留纵向滚动，提示文字曾被裁切。共用单行搜索在布局变化后归零 scrollY，保留 scrollX；最终测得 scrollY=0、文字上下边界在输入框内且垂直居中。
