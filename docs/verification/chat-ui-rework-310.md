# Monica Steam 聊天 UI 返工验证（2026-11-07）

已完成交接中的聊天 UI 返工，并按用户最新要求把多选操作改为与令牌列表共用的底部悬浮菜单。未发布版本1.0.310 / code18，最终Debug构建标识26110718-13。没有提交、推送、标签、发布或另行交付安装包。

## 最终行为

- 菜单位于 Dock 上方，提供数量、全选当前结果、置顶、归档、删除和退出。顶部筛选与会话行保持原位置；点击筛选退出多选。零选中时变更操作禁用，删除继续使用原确认框，取消删除保留选择，真实 Back 先退出多选。
- 复用令牌列表 SelectionActionBar 的样式；计数先让出操作按钮的空间。窄屏、大字号与1000选中时仍保留五个40dp按钮，视觉计数可能单行省略，完整数量保留于语义描述。
- 选择时长按切换该会话，原头像加载器继续存活，取消后直接恢复已加载照片。
- 筛选、搜索、账号上下文改变时使用新列表状态；同结果集的新消息更新保留阅读位置。
- 原生菜单重用时恢复alpha并取消旧退出回调；系统关闭动画仍可正常操作。
- 群头像按成员身份匹配照片，只在视觉信息变化时重绘；整组照片一起发布，用单张位图绘制抗锯齿圆形分区并居中裁切。最多四位代表成员，不把成员预览名单当作总人数。
