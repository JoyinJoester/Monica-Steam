## 变更与原因

- 成就集合、个人统计的完成状态筛选复用共享单行胶囊。M3E 使用高斯磨砂材质，液态玻璃使用现有折射透镜，支持按住浮起、拖动、松手提交和取消恢复；集合标题与胶囊留 14dp。两组筛选只采样独立页面背景，避免标题或透镜反馈到自身背景。
- 个人统计与游戏库详情复用圆角成就行，显示 56dp 图片、名称、说明及本地化解锁时间。透明容器明确使用主题文字色，保证深色标题可读。未解锁隐藏成就遮盖名称、说明和图片，不发起该图片加载。
- Aim Lab（714010）的真实公开定义提供图片文件名。旧 `/steamcommunity/public/images/apps/` 路径返回 HTTP 200，但内容是约 45KB 的 HTML 网页，原图片缓存正确拒绝它；新 `shared.akamai.steamstatic.com/community_assets/images/apps/` 路径返回真实 JPEG。相对文件名使用新路径，已缓存定义中的合法旧绝对 URL 也会转换；保留原 HTTPS、主机和文件名校验。
- 未完成成就优先实际灰色图片，失败再尝试正常图片；完成成就顺序相反。灰图不再额外降低透明度。个人主页成就对比同步按游戏 ID 解析文件名。
- 补齐日文、越南文、俄文成就集合资源。英文、中文、日文、越南文、俄文共 55 个实际编译值逐项匹配源资源，并检查字符串键唯一及格式占位符。
