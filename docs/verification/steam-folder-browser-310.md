# Monica folder browser for Steam collections · 1.0.310 (unreleased)

Steam library -> Steam collections uses the folder presentation extracted from Monica Android’s password library. Folder cards and unfiled games share the root directory; opening an ordinary collection shows its games and a path back to the root. Folder rows use the original 68dp minimum, 44dp circular icon, typography and grouped corners. Long-press opens the adapted Monica FolderActionsDialog for membership editing, rename and deletion. Floating controls create collections or edit membership. Name and deletion confirmation dialogs remain.

Game rows now use the existing Steam GameIcon and image cache at 44dp, showing Steam’s actual small icon when available and the existing fallback otherwise. Both directory browsing and membership editing use this compact row. Long-press owned games enters selection; adding skips already included IDs and preserves all other members. Removing from the current collection requires confirmation and does not delete library games. Hidden choices survive search, visible-only selection does not include shared games, and pending membership edits require discard confirmation on exit. Detail return retains the directory and query; foreground resume refreshes collections without dropping member drafts. Steam collections remain flat and may share games.

The reusable presentation is MonicaFolderBrowserPage plus the copied GroupedItemDefaults and adapted FolderActionsDialog. It intentionally receives folder data, game rows and callbacks without password or storage dependencies; the original VaultV2Pane is not invoked wholesale. The original Monica Android and F-Droid source trees were not edited. Previous shared top-bar/selection-widget files and cloud parser/service/ViewModel match their preceding-task baseline bytes. Fresh target comparisons, one-entry uploads, read-back verification and uncertain-write protection remain in place. No maFile or real account was accessed this turn. Earlier live create/rename/read/delete results remain in steam-collections-310.md; desktop Steam UI synchronization and real owned-game membership changes remain unverified.
