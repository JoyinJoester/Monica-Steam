# 聊天连接与创意工坊下载进度 — 1.0.310

日期：2026-11-07。未发布；本轮实现聊天连接和下载进度改进，不包含跨应用联动。

## 改动

- 相同账号、存储来源和凭据复用正在连接或已认证的 CM 套接字。引导信息的 120 秒缓存期限只影响后续登录，不再让健康连接上的请求重新获取令牌和节点列表。
- 优先复用已经连通的备用节点；并发调用不会仅因节点顺序不同而关闭同账号的可用连接。凭据变化后使用新目录，旧连接不再被判为当前凭据的健康连接。旧连接的迟到失败不会清除替代连接的引导缓存。
- 套接字失败通过按账号/存储来源路由的信号唤醒实时监督器，保留原有重试退避和健康检查兜底。唤醒本身不重置其它模块可能已经建立的替代连接。
- 已发送但响应丢失或等待被中断的请求，连接池不自动换节点重发。私聊、群聊将它交给已有历史确认流程；明确的 Steam 错误和响应超时保留原有分类。
- 创意工坊显示准备、下载、检查、保存四个阶段。SteamPipe 完成下载后检查清单中的文件摘要，以文件数显示校验进度；没有摘要的直链文件仅显示大小检查。保存阶段显示实际写入字节数，未知总量使用不定进度；旧版本保存任务中的下载计数不再显示为保存进度。
- 页面和通知共用阶段数据。写入与校验保留取消检查，完成状态仍在导出检查及最终目录重命名后发布。新文案包含英文、简中两套各 7 项。

参考 GameHub 的持久会话/事件路径分析，以及 DroidDeck 的阶段进度设计，自行实现上述改动；没有移入两项目源码或新增运行时依赖。DroidDeck 参考版本为 `aba55031c331cd0991c3d36788fb903a3ca30e78`，相关设计可见其 `stores/download/DownloadModels.kt`。
