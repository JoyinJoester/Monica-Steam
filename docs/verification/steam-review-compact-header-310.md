# Compact review header · 1.0.310 (unreleased)

The author row and separate large recommendation row are now a single compact header. A 40dp avatar sits beside the author name and a small thumb plus localized Recommended / Not recommended label. Playtime, playtime at review and date appear below the name. Long names ellipsize; recommendation text and metadata can wrap at larger font sizes. Card content spacing is reduced from 12dp to 8dp. No star rating is inferred from Steam's binary recommendation.

The existing author loading, avatar cache, identity cancellation and validated profile callback are retained. The whole header remains a profile target with a 48dp minimum height; invalid identities remain disabled. Body selection, rich text, review expansion and review labels are unchanged. No parser, service, database or account data changes. The 45 preserved paths include prior manual-card-share removal, game collections, liquid-glass motion and related achievement/profile data sources.
