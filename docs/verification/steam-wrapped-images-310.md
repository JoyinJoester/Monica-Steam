# Steam 内嵌链接图片解析修复（未发布 1.0.310）

2026-11-19。用户提供完整消息后，确认实际格式为 `[img src=... thumbnail_src=... srcset=... width=1260 height=2800][url=同一地址]同一地址[/url][/img]`。上一轮图片解析只允许图片内容为普通文字/URL，不接受内部链接标签；单独开放标签路径又留下链接与结束标签，最终整条消息回退文字，出现截图中的原始 BBCode。

## 修复

- 图片内容匹配增加单个完整 `[url]` 包装，保持不跨下一张开放图片标签的边界。
- 内部链接目标和可见 URL 必须相同；显式图片地址存在时也必须一致。不隐藏不同链接目标、说明文字、未知嵌套块或不完整结束标签。
- 没有显式图片地址时，从完整链接包装取得图片 URL；Steam 省略外层图片结束标签时，也可消费完整且地址一致的链接包装。
- 保留原图片 URL、宽高、说明、相册顺序、剧透、时间/发送状态、长按、失败重试及全屏查看器。没有修改消息缓存、上传、链接域名白名单或下载策略。
