## 行为与参考

商店和资料库共用游戏详情，分别默认进入商店与个人统计。固定游戏标题与标签，两个列表独立保留滚动位置；个人成就集合、已完成／未完成筛选切回后保留。标签复用现有 M3E／液态玻璃组件与减少动画设置。保留商店价格、套餐、评测、分享和适用的游戏数据／截图／工坊入口；资料库内分享回调接到聊天目的地，购物车能够打开并沿现有规则隐藏 Dock。

个人数据绑定当前账号、来源和 app ID，沿现有服务读取本人时长与成就。自购查询不到时仅查询当前玩家的游戏活动，不借用家庭出借者时长。缺失总时长不转换为零；缓存显示来源提示，读取失败保留缓存并允许重试。旧账号／旧游戏的成就响应拒绝发布，取消后即使底层返回也不能覆盖当前状态。复用既有加密缓存读取；本页新获取结果保留于当前详情会话，不覆盖整库快照。

参考用户提供的小黑盒商店／统计截图：同游戏切换、媒体和价格层级、本人时长与成就。原会话已下载并安装官方 APK，本轮没有登录或接受服务条款。Fluxdo 源码已在本地，版本 `8cf5cf291f39b5a685c379c0eea14f479c594563`、GPL-3.0；核对 topic_card_layout、topic_list_update_banner、topic_detail_page 的信息层级、显式新内容提示及阅读／回复状态。没有复制其代码，本次不包含社区整体重写。

本地 M3E Canvas 已保存可编辑 JSON 与完整链接，实际预览和商店→统计切换检查过。原生普通字号、1.5 倍字号深色、未登录、筛选以及液态玻璃页面截图已查看；图片和设计资料仅留忽略的 docs/design，不入库。
