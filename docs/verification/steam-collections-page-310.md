# Standalone Steam collections page · 1.0.310 (unreleased)

Steam library -> Steam collections opens an independent destination. Folder listing, browsing a collection's games and editing its membership are full-page screens. Name entry and deletion retain their confirmation dialogs. The collection list reuses the existing Monica Android password-library ExpressiveTopBar, UnifiedCategoryFilterChipMenuDropdown and CategoryListItem; the member editor reuses SelectionActionBar. Existing Steam game rows and the game-detail route are reused.

Folders can be searched; All, Unfiled and ordinary collections can be opened and switched through the category menu. The selected collection stays in the existing ViewModel, and a saveable-state holder retains browsing and search through detail navigation, keyed by storage/account/Steam ID. Foreground resume refreshes collections. Back first closes search, then returns to the folder list and finally the library. Dirty membership edits require discard confirmation. Search does not discard hidden pending edits; select-visible is idempotent, and clear-visible is separate. Existing unknown/unlisted member IDs remain untouched.

The first passing native batch exposed raw title clipping at large font. The page now reserves two header actions (category/search), places refresh in the category menu, and requests two-line ellipsis from the shared top bar. Other callers retain its prior overflow default. A real TextLayoutResult assertion checks the long-name ellipsis. Read-only entries use the shared folder row's new optional enabled flag; existing callers default to enabled.

Cloud parser/model, service and ViewModel bytes match the preceding collections task exactly. This UI change preserves fresh reviewed-target comparisons, one-entry uploads, read-back verification and uncertain-write protection. No real account or maFile was accessed this turn. Earlier live create/rename/read/delete and the 9-entry preservation result remain recorded in steam-collections-310.md; that account returned zero owned games. Desktop Steam UI synchronization and live membership changes remain unverified.
