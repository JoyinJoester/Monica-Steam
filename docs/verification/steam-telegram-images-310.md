# Steam 聊天图片气泡验证（未发布 1.0.310）

2026-11-19。按用户提供的 Telegram 图片消息参考调整 Monica Steam。图片附件直接构成圆角气泡，单图按图片比例显示；同一消息内的多图使用 2dp 间隔拼贴，纯图片的时间与发送状态以白色叠在右下角深色半透明底上。有说明时，说明与时间移至图片下方。相邻消息分组保留对应的小圆角。

## 范围与行为

- 解析同一条消息内最多十个有效图片标签，保持原始顺序和说明文字；读取可用的宽高，加载完成后用实际图片尺寸更新布局。普通图片 URL 仍可显示。
- 混合闭合标签与 Steam 无结束标签格式时不吞掉后续图片，不将重复的图片 URL 当成说明。超过十张、部分无效或残留未识别的富文本时回退文字，保留原内容。
- 单图完整显示，多图裁切拼贴。点击任意拼贴图片打开对应页，继续使用现有全屏查看器、翻页、下载限制以及缩略图展开和回落。
- 图片及说明文字长按触发原消息操作。保留回复预览、反应和发送失败重试；点击重试不会打开图片。
- 剧透首次点击只揭示，隐藏时不创建远程图片组件；减少动画时关闭图片展开和回落动画。沿用五种语言的查看器、剧透及操作文案。
- 相册只属于同一条消息，不合并相邻消息。上传仍沿用单文件流程，本轮未增加多选上传或原生交易功能。

## 构建与 JVM

JDK 17，离线 Gradle，两个 worker，独立 `.tgimages` 包后缀，x86_64 Debug，不混淆。构建参数及摘要见证据目录。

最终 60 个 JVM 测试类共 300 项，无失败、错误或跳过。包含 13 项新增图片解析与布局测试，并回归富媒体、个人卡片、通知、上传及图片查看器。布局检查涵盖 1–10 张、横竖图、极端/未知比例和小宽度，核对矩形边界、无重叠及完整覆盖。

首轮失败明确复现图片正则将无结束标签与下一张闭合图片一起匹配，导致第二张被吞掉。修改生产解析边界后保留相同测试断言通过。首次失败构建日志保留；首次失败 XML 未另存，证据中的 XML 均为最终通过结果。
