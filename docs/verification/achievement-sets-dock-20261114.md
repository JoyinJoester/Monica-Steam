# Steam 成就集合与 Dock 采样优化（2026-11-14）

未发布 1.0.310。已实现新版成就集合和 Dock 的稳定采样、零强度折射预置；未提交、推送、发布或交付 APK。

## 成就集合

对照 [Steam 官方公告](https://steamcommunity.com/games/593110/announcements/detail/685269908095762672) 和 [Player protobuf](https://raw.githubusercontent.com/SteamDatabase/Protobufs/master/webui/service_player.proto)。公开 Portal 2 JSON/真实 protobuf 共51项，合作22项、单人29项；CS2默认集合1项。无需账号或 API key 的公开 schema 仅用于合成验收夹具。

Rust MSA2 与 Kotlin 回退均保留 unsigned group ID、归档及隐藏标记，集合保存本体/DLC、排序、可用状态、完成标记和服务器计数。已完成标记与当前完成数量独立，归档成就不扩大集合完成条件。明确的开发者/非公开集合排除；兼容旧缓存和 MSA1 解码，旧 native 走 Kotlin 回退以保留分组。旧缓存仍按原数据显示，刷新取得新集合。库详情及比较页可按集合筛选，与原状态筛选组合；未解锁隐藏成就不显示名称、描述或其无障碍名称。

## Dock 修改与证据

指示器预留向上取整到整像素的最大采样边界，避免按压进度每帧改变离屏纹理尺寸和取整原点。零强度保留 identity shader，首次显示 Dock 时建立折射管线；shader 在零强度直接返回输入像素。折射10/14dp、色散0.5、外壳24dp、模糊4dp、颜色、高光、选中块变形、触摸拖动和减少动画参数保留，未升级依赖。

真实 Android 帧时钟，原生触摸，2次预热、12次拖动、20次点击，每轮要求34次选择回调；以下所有轮次断言通过，runtime shader启用、帧回调丢失0。帧数据反映这个隔离页面和共享主机环境，不能当真机全应用性能结果。GPU_DURATION在本机为0，未提供GPU耗时证据。
