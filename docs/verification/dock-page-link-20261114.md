# Dock 与页面联动验证（2026-11-14）

本轮继续用户“卡顿可能与页面联动有关”的反馈。此前的 Steam 成就集合与玻璃采样修复保留。

## 发现与修改

保留页面的宿主已经停止隐藏页生命周期，但聊天外层六个 UI 状态流与游戏库／UI 设置流仍使用普通 collectAsState。实际页面测试确认隐藏聊天仍有一个 UI 订阅，原版游戏库与聊天的隐藏订阅检查均失败。改为 collectAsStateWithLifecycle；后台消息与 ViewModel 工作保留，返回时接收最新状态。

聊天每次输入／连接状态更新还会重新分配、整理及排序全部会话行。将实际调用的列表投影按会话、群组、好友、搜索、局部标记和语音状态缓存，并复用过滤结果及未读计数。未变行复用检查原逻辑失败；新消息、好友名称、群组、语音、置顶、归档、隐藏与新消息重新出现等依赖检查通过。没有改变玻璃、Dock 动画、拖动手势、导航时序或依赖版本。

独立原生内容视图的生命周期假设被测试排除：当前 AndroidView 边界已传递页面生命周期，无需另外修改。屏幕截图确认最新会话显示正常；Compose 虚拟时钟对嵌套根的显示判断不能作为整页视觉验证，最终回归改用真实 Android 帧时钟、实际未读回调、系统可见标记及屏幕范围。原生会话格以内容描述提供名称，匹配文本和内容描述，未取消可见性断言。

## 测量

复用既有 MuMu index2，API35/x86_64，AGSL 实际启用。独立 pagelink 测试包，无 INTERNET，400 个合成游戏及100条合成会话；真实 SteamLibraryScreen、SteamChatScreen 外层、PageHost 和 Dock。先预热6次，每轮30次原生点击，逐次等待目标页的实际帧提交，并断言30个选择回调／30次提交；注入20ms间隔的聊天状态模拟消息状态突发。该负载不代表真实网络频率。性能测量期间无宿主 Gradle 构建。

此前同包仅隔离聊天收集的 B→C→C→B 对照中，总帧 P95 没有稳定下降，不能把全部改善归于取消隐藏订阅。安静状态与状态突发对照、关闭全页采样及关闭顶部玻璃的诊断轮次也保留；单独关闭这些效果仍有长帧。最终包含列表缓存的反向对照支持页面联动是一个实际因素，仍有残余长帧。
