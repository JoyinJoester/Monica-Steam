# 反复切回聊天会话列表的绘制优化（2026-11-14）

未发布 1.0.310。用户反馈 vivo X100 在发消息前的最新版中，每次 Dock 切回会话列表都会卡顿。已针对重复进入时的页面背景录制成本修改，并保留本轮成就集合与七类常用底部弹层改版。未提交、推送、发布、改版本号或交付 APK。

## 原因与最终行为

使用实际 SteamLibraryScreen、SteamChatScreen、PageHost 和玻璃 Dock，以 400 个游戏、100 个会话的离线合成数据驱动原生触摸和 Android 帧时钟。逐方向计数，避免把进入聊天与返回库的耗时混合。

原生会话名字布局在 84 次保留单元观察中没有重建。停止状态注入、移除外层背景捕获、移除导航装饰、单独加稳定图层、改为共享 SteamGlassHost 均未产生可靠收益，相关生产候选已撤销。临时 atrace 标记定位到聊天背景源录制 median 11.349ms，库背景 6.111ms；原生 Dialog 绘制仅 0.191ms、头像 0.026ms。主绘制 CPU 接近对应墙钟耗时，说明重复录制是本机可定位的成本。trace 包含启动和有限缓冲区丢失，仅用于归因，不用作最终性能验收。

最终 SteamTabPageHost 让有界的已访问库／聊天页面保持测量和放置，每页使用稳定的裁剪图层，活动页 alpha=1 且位于上层，隐藏页 alpha=0 并清除语义。返回时可复用页面录制背景，避免因解除放置反复失效。隐藏页保持 CREATED 生命周期并暂停 UI 收集；切页清理焦点，后台、窗口失焦及平台 View 路由继续释放非活动缓存。其他页面保留原过渡。

没有移除折射、模糊、阴影、选中形变或筛选拖动。没有修改认证、消息发送、账号切换及网络协议。

## 最终反向对照

无并行 Gradle 构建，修复→修复→旧版→旧版→修复；两种主包使用同一最终测试 APK，每次安装后 ART speed 编译。每轮要求 30 次选择回调、30 次帧提交，其中聊天／库各 15 次；五轮无丢失指标、隐藏聊天 UI 订阅数为 0。旧主包为修复前归档，包哈希与最终测试包哈希保留。

## 功能与构建

最终夹具主／测试包构建 178.870s；最终 16 项设备回归全部通过，runner 26.302s。覆盖生命周期、草稿、返回、后台竞态、平台页释放，原生触摸／无障碍，真正 KEYCODE_A 只进入当前原生编辑器，隐藏页焦点释放、原生内容更新，持有／已释放手势取消、RTL 拖动、竖向滚动、identity 像素与正折射、材料和样式切换保留草稿。

实际会话列表恢复最新状态另 1 项通过，runner 6.680s；隐藏订阅 0、活动订阅 1。截图已查看，显示新合成会话与未读标记；图片仅留忽略的 docs/design 目录。这个功能复测与正式构建并行，不纳入性能比较。

正式 application ID、x86_64、默认 R8／资源压缩 Debug 构建 832.200s 成功，13 项相关 JVM 测试无失败／错误／跳过（会话列表、冷切页 guard、Dock motion 三类）。包为 1.0.310、非 debuggable，R8 mapping 已生成，包内全部 native 与最终设备夹具逐字节一致。设备测试运行独立离线夹具，不能称正式 R8 包的完整设备验收。

fixture-final09 的早期 JVM 过滤器误写两个不存在类，仅 Dock motion 实际运行；本次 production01 已用正确三类补齐。不把早期数量当作最终完整测试。直接调用隐藏内部 View.requestFocus 的人工断言在旧实现也失败，日志保留，最终改为真实键盘路由检查；不声称拦截任意程序化焦点请求。ART sampling trace09 阻塞且零字节，强停自有夹具后排除；atrace17 输出路径冲突与早期生成器括号错误也保留本地原始记录。
