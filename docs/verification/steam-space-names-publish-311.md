# 蒸蒸空间游戏名、FAB 与原生文字发布 — 2026-11-22

版本保持未发布 1.0.311 / code 18。本轮处理动态仍显示游戏 ID、发布入口改为 FAB，以及原生发布页面的可行性与实现。

## 最终行为

- 游戏名保留官方 `IStoreBrowseService/GetItems/v1/` 批量查询；缺项或非认证故障时，补查公开商店 `api/appdetails`。公开请求不带账号 token 或 Cookie，核对 success、返回 app ID、名称长度和响应大小，只缓存确认结果，按语言和 app ID 隔离。批量请求 4 秒，单个公开请求 3 秒；每次最多补查 8 项，在 16 秒调度预算内启动请求，正在执行的最后一个请求可能继续到自身超时。另在后台复用当前账号游戏库的已有名称缓存，新闻刷新失败仍可补全缓存动态。账号/语言切换取消旧读取，临时账号不读取持久游戏库缓存，已有有效名称与事件原文保留。
- 无账号公开实测确认 `815370 → 绿色地狱`、`1091500 → 赛博朋克 2077`。用户设备上批量查询缺名的实际网络原因未被捕获；受控空批量响应通过生产服务、公开补查解析和原生组件显示两个游戏名。下架、隐私、接口缺项、网络失败或本次查询额度不足仍可能保留编号，不能保证所有 ID 总能查到名字。
- 发布入口移为右下 56dp FAB，复用现有 M3E/液态玻璃组件并按实际 Dock 高度避让；动态列表预留相应底部空间。正常字号与 1.5 字号的生产组件截图已查看。
- 原生页面支持向 Steam 好友发布文字动态，使用 `Player.PostStatusToFriends#1`，一般动态 appid=0，status_text 保留原文与换行。已核对 SteamDatabase 当前公开 protobuf；现有 CM 层负责响应 job 与 EResult 检查。页面保留官方网页入口，图片发布仍未实现。
- 草稿只在内存中。空白、超限 1000 字符及 NUL 拒绝提交；仅用户点击发送，等待时禁止重复点击、改文和退出。会话准备失败可继续编辑；进入发送后异常保守视为结果不明，保留草稿并禁用重发，要求先在 Steam 核实。后台取消本地等待，不承诺撤回已发请求；收到确认后才提示成功并刷新。离开草稿需要确认，切换账号/离开清理草稿。
- 原来的“在 Steam 查看”仍将原始链接交给外部浏览器；可选发布网页仍为应用内官方页面。这两个动作目的不同。发行说明与中英 README 已同步，不再保留发布入口为文字按钮或只能通过网页发布的过时描述。
