# 悬浮工具栏圆角裁剪与液体张力 · 1.0.310 未发布

本轮仅修改 Monica Steam。修复悬浮工具栏两侧圆角外的矩形残片，并实现先接触、后压平交界、再回弹为张力圆角；提起时保留连接，弹性拉伸，两端缝隙向中央收拢，颈部收细后断开。玻璃、底色、高光及可点击内容使用同一轮廓。展开和收起使用单一活跃表面的尺寸动画，保留 48dp 操作目标、保存的吸附边和纵向位置、取消拖动、自动收起及减少动画设置。

原玻璃底层 onDrawBehind 绘制未按形状裁剪的矩形；零半径 dropShadow 仍会画出旧轮廓。移除不需要的零半径阴影，并按实际轮廓绘制底色。进一步在 MuMu 确定性复现 Backdrop 2.0.1 更新形状但固定尺寸的 placement clip 保留旧遮罩的问题：接触参数改变而画面未压平。TOOLBAR 改由外层 Compose clip 负责动态轮廓，内层背景模糊保持矩形，避免旧遮罩切去新压平的角或连接。筛选和 Dock 的透镜逻辑保留。

接触依据实际呈现距离判定，未接触时不提前改变圆角。接触后 85ms 压平，再由弹簧形成 5dp 张力角；提起后恢复完整圆角并保留最长 28dp 的连接。连接根部与颈部连续向中央收拢，颈部更快变细；断开后退役连接。物理左右边独立处理，弹簧输出限制在原可用区域。减少动画时直接落到静态状态。
