# 蒸蒸空间空好友区域与动态缓存（2026-11-07）

没有正在游戏的好友时，蒸蒸空间直接显示“最近动态”，不再显示“暂时没有好友在游戏中”、好友加载/失败占位或额外空行。有正在游戏的好友时继续沿用原头像横栏与上滑收起行为。

动态新增账号与语言隔离的缓存。5分钟内再次进入直接复用完整已加载列表和分页状态；超过5分钟先显示已有内容再刷新，刷新失败保留列表并沿用原有旧数据提示。手动刷新始终可用，成功空结果也缓存。离开页面或进入后台仍取消未完成请求并清空可见动态；已完成内容留在有界缓存，后台保存不会重新发布到页面。

## 缓存实现

- 内存最多4组账号/语言快照，每组最多400条/20页；每组字符串总量512Ki字符，整个持久化JSON最多2Mi字符，读取保留期24小时。超限数据本次仍可展示，只是不缓存该快照。
- 本地账号按本地ID、SteamID、语言、临时属性与创建时间隔离。MDBX的投影创建时间每次读取都改变，最终仅对已保存的负ID账号忽略此合成时间；其稳定负ID来自数据库ID与条目UUID，仍与SteamID/语言共同隔离。临时账号只留内存。
- 动态使用现有 `SecurityManager.encryptDataLegacyCompat` C2兼容加密；不序列化SteamAccount、令牌、Cookie或密钥。明文透传、坏密文、错误版本、过期和身份不符均不恢复；加密失败不回退明文，缓存失效不删除原缓存字节。
- 主线程只读/写有界内存，磁盘与cipher按需在IO调度器初始化。网络成功后先写内存并发布页面，再异步保存；排序和串行磁盘锁拒绝迟到旧快照覆盖新的刷新或分页结果。
- 磁盘读取有1.5秒协程超时，已验证可中断读取回退网络；不可中断的Keystore/Binder或monitor等待不属于硬截止保证。应用进程若在异步提交前退出，最近一次可选缓存可能未落盘；本次不承诺所有异常退出都保留最新动态。
