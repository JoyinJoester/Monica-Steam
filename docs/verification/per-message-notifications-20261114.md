# Steam 逐条私聊系统通知验证（2026-11-14）

旧实现为同一会话复用通知 tag/id，并显示最近六条消息；新消息会覆盖此前那条系统通知。现按账号来源、会话和服务器 timestamp/ordinal 的完整摘要分配独立通知标识，每条通知只包含当前消息，重复推送继续使用原有持久去重。保留现有后台私聊开关、高优先级消息通道、静默前台服务通知、富消息预览、不可变 PendingIntent 和私密 publicVersion。

通知可按账号分组，子通知独立存在；Android 通知栏的折叠表现由系统管理。会话清理从 Android 当前通知记录查询，不依赖进程内消息历史；服务或发布器重建后仍能清理精确来源/会话，并兼容旧版本的会话通知。PendingIntent 增加不含明文账号的完整会话摘要 URI，防止整数 requestCode 碰撞使点击目标串到其他会话。

最多保留最近 40 条独立消息通知，按发布时间淘汰最旧消息，不淘汰前台服务或其他功能通知。此限制为 Android 的应用通知数量上限预留容量；其他通知耗尽预留容量时，系统仍可能限制新通知。

- 独立离线测试包 fixture02 构建及 23 项 JVM 测试通过，耗时 49.393 秒；其中 15 项为标识/去重/消息决策测试，8 项为既有集成与展示源码保护检查。
- 复用已运行的公共 `Monica_Issue136_API_32` / emulator-5556 / API32 / x86_64。六项不同设备方法整批通过，runner 13.934 秒；另单独复测一次通知栏截图方法通过，runner 1.686 秒，不计为新的不同方法。
- 正常应用启用 R8 的构建通过，耗时 533.590 秒。包名、非 debuggable、INTERNET 权限、x86_64、本机库哈希及 mapping 均核对；版本保持 1.0.310 / code18。正常应用包只构建，设备运行的是独立离线测试包。
