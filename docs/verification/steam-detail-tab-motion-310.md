# Steam 1.0.310 游戏详情顶部切换动效

2026-11-21；versionCode 18，未发布。

用户视频显示 M3E 成就筛选有位移，而顶部商店／个人统计的选中背景直接换位。完整解码用户视频 195 帧（6.500 秒），检查联系表。根因是 SteamGameDetailTabLayout 把导航置于 AnimatedContent 的每个页面分支，页面切换会销毁旧导航、创建已处于目标位置的新导航。此前独立导航组件测试没有覆盖这个真实页面组合。

## 实现

- 一份 SteamGameDetailNavigation 留在正文 AnimatedContent 外，M3E 继续使用共享 220ms 选中背景动画，液态玻璃继续使用既有 Dock 共用引擎和镜片。
- 各页原导航位置保留实际测量高度的占位，注册该页原玻璃背景源和当前返回处理；不新加背景捕获层。正文保留原淡入淡出、保存状态及工具栏。
- 工坊详情／导入／下载子页不提供共享头部时不放置顶部导航，同时清除其无障碍语义；返回根页保留导航自身状态。不会向工坊子页暴露第二个返回按钮。
- 本轮仅修改一份生产 Kotlin 文件、完整详情页测试及中英文未发布说明，保留既有卡片和共用 Dock 工作。
