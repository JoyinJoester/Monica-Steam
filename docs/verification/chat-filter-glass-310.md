# Chat filter floating glass — 2026-11-20

Monica Steam remains on unreleased 1.0.310/code18. The conversation filter now places its glass shell behind the selection row as a sibling, allowing the existing Dock-style lens to expand outside the capsule while held. Previously, the Kyant backdrop's clipped child layer cut it off. Only the conversation filter enables the new option; other filters retain their existing behavior. Dragging, nearest-slot release, cancellation, large text, RTL and edge scrolling retain the existing state machine.

Chat call controls adapt Telegram's short press, icon and state-color transitions: a 0.9 press scale, 150 ms transitions, distinct hang-up treatment and muted-state color. The existing actions, audio routing and signaling are unchanged. Accessibility descriptions change immediately, and reduced motion skips the added animations. Existing labels are reused; no new product strings were introduced. The local Telegram review and deferred effects are in `chat-filter-glass-310-telegram-review.md`. Audio-driven avatar waves were not added because the current Steam state does not expose speaking amplitude.
