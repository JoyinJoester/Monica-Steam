## 页面顺序

详情页依次显示封面、平台与单行标签、当前区价格与比价入口、版本与购买、介绍与截图、SteamDB／创意工坊等资料、玩家评测。游戏名只保留在固定顶栏中；顶栏菜单可直接跳到版本或评测。愿望单和忽略使用轻量操作。

当前区服置顶指多区比价列表。以账号区服为准，未知时回退到当前详情的定价地区。当前区服自动加入查询；旧缓存缺少该区服时需要重新加载。其他可售地区按人民币换算价格排列，未知换算和不可售地区靠后。

价格列表使用一致的“区服／现价与折扣／原价”三列，默认全部收起，点一行仅展开该区的史低摘要。首行与其他行对齐，所有区服都有国旗 emoji；中国香港和中国台湾都使用中国国旗。Windows Canvas 的 emoji 字体可能显示地区字母，Android 的实际国旗效果见原生截图。

人民币金额省略无意义的小数末尾零，当地币种只显示一次。免费与不可售状态不占用大段提示。原价使用次要字号，给窄屏大字体留出空间。

## SteamDB 数据边界

当前扩展接口提供历史最低价、折扣、可选近两年最低价、出现次数和最近日期，没有完整价格时间序列。因此没有绘制历史曲线，也不会据此推断“新史低”。展开的史低金额保留 SteamDB 原始币种，不和人民币实时换算值混作同一价格。
