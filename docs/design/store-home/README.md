# Monica Steam 商店主页

2026-10-05。以默认打开的商店页为范围，采用 Gmail 风格的一体搜索顶栏，并保留原有悬浮购物车。

## 最终布局

- 菜单、搜索、账号合为一条搜索栏，取消独立标题行。
- 栏目使用单行可横向滚动的文字标签，高级筛选固定在同一行右侧；愿望单、喜加一、积分商店、产品激活、工坊导入、通知和设置收进菜单。
- 购物车继续悬浮在底部导航上方；键盘打开时隐藏，列表底部预留空间以便完整查看最后一项。
- 首页去掉大幅首卡，使用紧凑特惠封面、热销列表和各栏“查看全部”。卡片高度随字体增长，价格与折扣可换行。
- 搜索加载时不展示上一页内容；详情返回后保留浏览位置，切换栏目时回到顶部。

沿用用户的 Material 3 配色、字体和底部导航配置。常规字号下，顶部控制区为一体搜索栏和一行栏目，设备测试要求二者合计不超过 128dp；没有通过缩小触摸区域压缩布局。

## 验证

- 公共 AVD `Monica_Issue136_API_32`，Android 32 / x86_64；独立测试包 `takagi.ru.monica.steam.recoverytest`。
- 6 项设备交互测试通过：一体顶栏与各入口、栏目和“查看全部”、搜索等待与清除、离线重试、详情返回位置、深色和大字体下的价格及菜单可达性。
- 37 项商店回归单元测试通过：商店解析、目录分页数据、币种、栏目、筛选、提示、列表 key、忽略状态、购物车、愿望单和详情历史。
- Debug、设备测试包及普通配置 Release 构建通过。旧的大首卡、固定卡片高度和源码位置断言由设备上的行为验证替代；没有重复运行上一任务已确认存在失败的完整套件。
- 真实 Activity 已检查搜索栏、栏目、悬浮购物车与底部导航的位置，并实测点击悬浮购物车打开购物车页面。模拟器实时商店请求不可用，因此内容交互使用公开样本独立验证。
