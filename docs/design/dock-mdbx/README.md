## 行为修正

- Steam 的印度区公开 featuredcategories 数据将 Steam Machine（4165910）重复四次、Steam Frame（4165890）重复两次，且类型均为 app，简单去重不足以得到游戏榜单。首页热销改用带 `category1=998` 的游戏目录；失败时不回退到硬件。其余推荐项去重，未定价且未明确免费时不显示免费。首页缓存升级，避免继续展示旧硬件列表。
- MDBX3 是唯一日常引擎。旧库从账号来源、默认库、普通凭据查询及同步中排除，但保留注册记录、源文件和升级读取器。旧库升级写入独立的 MDBX3 本地库，校验附件和源文件指纹；远程旧库只能升级现有本机副本。升级失败可重试。移除旧库注册不删除原始文件。
- 与 Android 保持一致：持久化标识 `RUST_MDBX2`、MDBX-2 格式和 FFI 名称保持兼容，不将未知旧标识直接解释为现代引擎。运行时为固定的 MDBX3 `3.0.0-alpha.1` preview，详情见 [runtime 说明](../../mdbx3-runtime.md)。

## Dock 绘制与性能范围

玻璃外壳的背景采样供选中指示器复用；隐藏的选中图标层只绘制前景，减少重复模糊和折射处理。图标／文字使用缓存的白色字形，颜色过渡在 graphicsLayer 执行；倾斜高光共用一个传感器订阅，并在绘制阶段读取状态。

离线测试使用 100 行列表、真实页面切换与 Dock、20 次切换、450ms 间隔，收集 Window FrameMetrics。Android 32 公共 AVD 不支持 RuntimeShader，以下数据仅覆盖回退绘制路径：

| 版本 | 帧数 | p50 | p90 | p95 | >32ms 帧数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 修改前 | 424 | 20.65ms | 37.59ms | 52.61ms | 96 |
| 修改后 | 423 | 21.28ms | 38.71ms | 54.71ms | 96 |

这组结果不能证明帧率提升。支持 RuntimeShader 的现有 Android 36 AVD 在启动阶段发生 SurfaceFlinger / GoldfishMapper 断言崩溃；Android 35 AVD 发生系统 PackageManager 空指针并反复重启，用户存储未解锁，均未形成有效应用测量。因此玻璃着色路径的视觉效果和性能改善仍需在可正常运行的 Android 13+ 设备补验，不能由 API 32 结果推断。临时旧 Dock 对照实现已从测试源码移除，保留可重复的 `SteamDockFrameTest`。
